## ⚡ Automatic LeetCode → GitHub Sync

This repository uses **GitHub Actions** to automatically synchronize my LeetCode submissions.

Whenever the workflow runs, it fetches my submissions from LeetCode and commits the solutions into this repository.

### Workflow

```text
LeetCode
    ↓
GitHub Actions
    ↓
LeetCode Sync
    ↓
solutions/
    ↓
GitHub Repository
```

This allows the repository to continuously document my DSA practice without manually copying every solution.

---

## 🔐 Security

Authentication credentials required for the synchronization workflow are stored using **GitHub Actions Secrets**.

Sensitive credentials are **not stored inside the source code or README**.

The workflow uses a restricted GitHub token permission:

```yaml
permissions:
  contents: write
```

The third-party GitHub Action is also pinned to a specific commit SHA instead of relying on a floating version tag.
